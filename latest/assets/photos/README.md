# Photography

Aerial photographs, toned in the brand's dark blues. Set type over a photograph only on a scrim (`s-color-scrim-dark` or `s-color-scrim-light`) with the pinned inks.

- `hero-wide.jpg`: 2871 × 1250, the full-bleed hero (`data-media="16-9"`).
- `band-wide.jpg`: 2560 × 875, a wide band or section opener.
- `band-night.jpg`: 2400 × 1045, the same subject at night, for a dark band.
- `hero-square.jpg`: 1400 × 1400, the split hero (`data-media="1-1"`) and square tiles.
